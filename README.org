#+TITLE: org-typst-math
#+OPTIONS: toc:nil

Write Typst math inside Org's math delimiters. A persistent Rust helper converts
formulas to SVG previews, MathML for HTML export, or LaTeX. The community
ox-typst exporter handles whole-document Typst export.
Requires Emacs 30.2+ and Org 9.7.11+; no compatibility layer is included.

* Installation

#+begin_src sh
git clone https://github.com/DzmingLi/org-typst-math.git
cd org-typst-math
nix profile install .
nix build .#elisp --out-link result-elisp
#+end_src

The profile installation provides the Rust helper. Install the Elisp archives
with =package-install-file= as described below. When the helper is on Emacs's
PATH, there is no need to set =typst-client-command=.
You can also build the helper with =nix build=, or run =cargo build= in the
development shell.

* Development environment and usage

=flake.nix= provides the development environment, pinned by =flake.lock=.
It includes the Rust toolchain, Emacs 31, Org, ox-typst, and the Typst CLI.
Install TeX separately for LaTeX-to-PDF export. The helper links directly to
Typst's Rust libraries and does not invoke the CLI.

Use the standard Org export menu in an example buffer:

| Keys          | Output                  |
|---------------+-------------------------|
| =C-c C-e h h= | HTML                    |
| =C-c C-e y f= | Typst                   |
| =C-c C-e l l= | LaTeX                   |
| =C-c C-e l p= | PDF through LaTeX       |
| =C-c C-e y p= | PDF through ox-typst    |

Documents declaring =TYPST_MATH: t= automatically use this package's derived
exporters. Other documents retain their usual export behavior.

Enter the development shell with =nix develop=. It adds the project's
=target/debug= directory to PATH. To load a checkout in an existing Emacs
session, adjust these paths:

#+begin_src emacs-lisp
(add-to-list 'load-path (expand-file-name "~/src/org-typst-math/lisp"))
(setq typst-client-command
      (list (expand-file-name "~/src/org-typst-math/target/debug/org-typst-math-helper")))
(require 'org-typst-math)
(require 'ox-typst nil t)  ; Optional: whole-document Typst/PDF export only.
#+end_src

HTML export needs only the compiled helper and the org-typst-math Elisp package. It does not require the Typst CLI or ox-typst.
Use =cargo build --release= for an optimized helper, then update
=typst-client-command= accordingly.

* Document syntax

#+begin_example
#+TYPST_MATH: t
#+TYPST_HEADER: #let vect(x) = math.bold(x)
#+TYPST_HEADER: #import "math-defs.typ": *

Inline $vect(v)$, or \(frac(a, b)\).

\[
sum_(k=1)^n k = (n(n+1))/2
\]
#+end_example

Provide the imported file or remove the import from this example.
Multiple =TYPST_HEADER= entries are concatenated in order. Local imports resolve
relative to the Org document's directory; dependencies are reread on each
HTML/LaTeX export.

=$...$= and =\(...\)= contain inline math; =$$...$$= and =\[...\]= contain
display math. Recognition follows Org's parser, so source blocks and verbatim
text are not scanned as math.

=org-typst-math-mode= controls editing behavior without modifying the file.
Export uses the document declaration or the =:typst-math t= option passed to
=org-export-as=. Selecting =typst-math-html=, =typst-math-latex=, or
=typst-math-typst= explicitly also enables the corresponding exporter.
Load ox-typst before using the derived Typst exporter.

* Displaying Unicode symbols

When =org-pretty-entities= is enabled, Typst math identifiers listed in
=org-typst-math-entities= are displayed as Unicode characters inside math
fragments. This is display-only: the source text, previews, and exports keep
the original Typst identifiers.

#+begin_example
#+STARTUP: entitiespretty

$alpha + beta = gamma$   ; displays as α + β = γ
#+end_example

Greek letters and a few common operators (such as =integral=, =sum=,
=dif=, =compose=, =dot=, =eq.not=, and =tack.r=) are recognized by default. Customize
=M-x customize-variable RET org-typst-math-entities= to add more symbols, for
example =("infinity" . "∞")= or =("partial" . "∂")=, or set it to nil to
prettify nothing. =M-x org-toggle-pretty-entities= and
=#+STARTUP: entitiespretty= work as usual, and compositions are removed when
=org-typst-math-mode= is disabled.

* Packages and processes

| Package or module | Files | Dependencies |
|-------------------+-------+--------------|
| Internal client module | lisp/typst-client.el | Included in org-typst-math |
| org-typst-math | lisp/org-typst-math.el, lisp/org-typst-math-export.el | Org, Emacs jsonrpc |

| Built-in preview module | lisp/org-typst-math-preview.el | Included in org-typst-math |

Build the org-typst-math archive:

#+begin_src sh
nix build .#elisp --out-link result-elisp
#+end_src

Use =M-x package-install-file= to install =org-typst-math-0.1.0.tar=
from =result-elisp/=. Configure the helper path if
needed, then evaluate =(require 'org-typst-math)=. For automatic preview toggling, install
[[https://github.com/DzmingLi/org-fragtog-plus][org-fragtog-plus]] from its separate repository.
The Rust helper is built separately and is not included in the Elisp archives.

For package managers that select source files, include =lisp/org-typst-math*.el=
and =lisp/typst-client.el= in org-typst-math. The client, export, and preview
modules are internal parts of this package. The optional toggling package is maintained in its own repository.

The client reuses one connection per document directory. Each HTML/LaTeX
export collects all math fragments into one batch JSON-RPC request. Rust retains
the font database and Typst compilation cache; there is no disk result cache
or separate process per formula.

Typst export passes through math source and headers without using the helper.
=M-x typst-client-stop= closes existing processes; subsequent requests restart
them automatically. The client also provides asynchronous conversion for previews.

* Math environments and custom blocks

Configure aliases with =M-x customize-variable RET org-typst-math-block-alist=,
or set them directly:

#+begin_src emacs-lisp
(setq org-typst-math-block-alist
      '(("typst-theorem" . "theorem")
        ("typst-example" . "example")
        ("typst-proof" . "proof")))
#+end_src

The default mapping is empty. Only configured special blocks are converted,
and arbitrary environment names can be mapped. There is no automatic prefix
rule. The standard =begin_example= block remains a verbatim example block.

#+begin_example
#+NAME: my-theorem
#+ATTR_TYPST: :title [A theorem] :numbering none
#+ATTR_LATEX: :options [A theorem]
#+begin_typst-theorem
For real $x$, $x^2 >= 0$.
#+end_typst-theorem

See [[my-theorem][the theorem]].
#+end_example

Typst output is =#theorem(title: [A theorem], numbering: none)[...]=.
=:positional= supplies positional arguments; all other keys retain their names.
Values are raw Typst expressions, such as =:name "Title"=,
=:positional [Title]=, =:outlined false=, or =:fill rgb("#fff")=.
Positional arguments can be repeated, and attributes can span multiple
ATTR_TYPST lines.

By default, NAME produces a trailing label matching Org links. To pass a label
as an argument instead, use =:label <thm:one>= while keeping NAME as the Org
link target.

LaTeX uses the mapped environment name and ATTR_LATEX; HTML uses the mapped
class and ATTR_HTML. Typst arguments are not translated into HTML or LaTeX
attributes. HTML theorem numbering is not generated automatically.

See [[file:examples/blocks.org][blocks.org]] for a complete example. Its theorion setup lives in a
=begin_export typst= block at the top of the document. This setup applies only
to whole-document Typst export and is not passed to the math helper.
After configuring the aliases above, export the example through the standard
Org menu. Math macros still belong in TYPST_HEADER.

* Built-in previews and org-fragtog-plus

Previews are included in org-typst-math and share the persistent helper with
export. They require graphical Emacs 30.2+ with SVG support.
Display formulas are centered in the window's text area; inline formulas stay
in place. Centering adjusts with the window width and disappears when source
is revealed.

- =M-x org-typst-preview=: asynchronously preview all math in the buffer;
  with a prefix argument, clear previews.
- =M-x org-typst-math-preview-refresh= and =org-typst-math-preview-clear=:
  explicitly refresh or clear previews.
- =M-x org-typst-math-preview-diagnostics=: view errors and their locations.

[[https://github.com/DzmingLi/org-fragtog-plus][org-fragtog-plus]] is an independent, optional package in a separate repository. It uses Org's built-in
LaTeX preview by default. Enabling org-typst-math-mode selects the buffer-local
Typst backend; disabling it restores LaTeX.
It neither depends on nor advises the original org-fragtog package.
Do not enable both toggling modes in the same buffer.

#+begin_src emacs-lisp
(require 'org-typst-math)
(require 'org-fragtog-plus)
;; In an Org buffer using Typst math:
(org-typst-math-mode 1)
(org-fragtog-plus-mode 1)
(org-typst-preview) ; Optional: preview the entire buffer immediately.
#+end_src

Entering a formula reveals its source; leaving it restores the image, requesting
a new SVG when needed. =org-fragtog-plus-delay= sets the idle delay before
revealing source, in seconds (default 0). Each render automatically scales
the helper's 12pt output to the current frame's default face size.
Refresh previews after changing the default font size.
Inline images reserve extra vertical space using
=org-typst-math-preview-inline-padding= (default 6 pixels). SVG bounds include
the full formula, so fractions and scripts can expand the line height.

Editing a formula invalidates its image immediately. Manual preview remains
available without org-fragtog-plus. Disabling automatic toggling clears the
backend's previews and invalidates pending results.

** Extending the backend

=org-fragtog-plus-backend= is a buffer-local function accepting ACTION and an
optional FRAGMENT. Use =org-fragtog-plus-set-backend= to switch backends in an
active buffer; it clears the previous backend's state first.

| ACTION | Behavior |
|--------+----------|
| fragment | Return the Org element at point, or nil; exclude trailing whitespace |
| show | Display FRAGMENT's preview; repeated calls must not toggle it off |
| hide | Reveal FRAGMENT's source; repeated calls must not toggle it back |
| clear | Clear buffer previews and invalidate pending results |

Asynchronous backends should keep the formula at point visible as source when
installing results. The Typst adapter reuses existing SVG batching, caching,
and diagnostics. org-fragtog-plus itself does not need to know about Rust or Typst.
